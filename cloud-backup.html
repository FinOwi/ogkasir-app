Kenapa Ini Penting

Kebayang Kalau HP Kasirmu Hilang Besok?

Semua data usahamu — transaksi, stok, laporan — hidup di satu HP. Satu kejadian, semuanya bisa lenyap.

📱💥

HP Rusak / Mati Total

Kehujanan, jatuh, bootloop. Servis bisa seminggu — data di dalamnya? Belum tentu selamat.

🏃💨

HP Hilang / Dicuri

Tertinggal di ojek, diambil orang. Catatan penjualan berbulan-bulan ikut raib begitu saja.

🔄😰

Ganti HP Baru

HP lama lemot, mau ganti baru — pindahin data kasir manual? Ribet dan rawan ada yang kelewat.

Cara Kerja

Semudah 3 Ketuk

Nggak perlu akun, nggak perlu ingat password. Cukup sekali setting.

1

Backup Sekali Ketuk

Di Pengaturan → Data & Backup, ketuk Backup ke Cloud. Aplikasi memberimu kode pemulihan pribadi — catat & simpan baik-baik.

2

Data Tersimpan Aman

Seluruh data kasir — transaksi, menu, stok, pengaturan — tersimpan terenkripsi di cloud FinOwi. HP-mu tetap jalan offline seperti biasa.

3

Pulihkan Kapan Saja

HP baru? Install OGKasir, ketuk Pulihkan dari Cloud, masukkan kode pemulihanmu. Semua data kembali dalam hitungan menit.

Keamanan

Hanya Kamu yang Bisa Membuka

Backup-mu dikunci kode pemulihan pribadimu. Bahkan kami pun tidak bisa mengintip isinya.

🔑

Kode Milikmu Pribadi

12 karakter acak yang hanya kamu tahu. Tanpa kode ini, backup tidak bisa dibuka siapa pun.

🛡️

Server FinOwi

Data tersimpan di infrastruktur cloud profesional — bukan di laptop seseorang. Terlindungi & selalu online.

📵

Tetap Offline-First

Cloud hanya untuk backup. Kasir harianmu tetap jalan 100% tanpa internet, seperti biasa.

Perbandingan

Tanpa vs Dengan Cloud Backup

😰 Tanpa Cloud Backup

  • ✕HP hilang = data lenyap selamanya
  • ✕Ganti HP = pindah data manual
  • ✕Harus ingat backup file sendiri
  • ✕Was-was tiap HP bermasalah

😌 Dengan Cloud Backup

  • ✓HP hilang = pulihkan dalam hitungan menit
  • ✓Ganti HP = masukkan kode, beres
  • ✓Backup otomatis ke cloud
  • ✓Tidur nyenyak, data aman

FAQ

Yang Sering Ditanyakan

Apakah dataku tetap aman di cloud?
Ya. Backup-mu hanya bisa dibuka dengan kode pemulihan pribadimu. Tanpa kode itu, tidak ada — termasuk kami — yang bisa membaca isinya.
Apakah kasirku jadi butuh internet terus?
Tidak. OGKasir tetap 100% offline untuk operasional harian. Internet hanya dipakai sesaat ketika kamu menekan tombol backup atau restore.
Berapa biayanya?
Gratis untuk semua pelanggan aktif OGKasir. Tidak ada biaya tambahan.
Bagaimana kalau kode pemulihanku hilang?
Kode pemulihan tidak bisa kami reset — itu justru yang bikin datamu aman. Simpan di tempat yang aman (catat di buku / password manager) begitu kamu menerimanya.
